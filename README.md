# Timetable-Generator 📅
### Smart Automated Timetable Generation System

Timetable Generator is a web-based application that automatically creates optimized class timetables by considering subjects, faculty availability, rooms, and constraints, reducing manual effort and scheduling conflicts.

---

## 🚀 Problem Statement
Manual timetable creation is time-consuming, error-prone, and difficult to manage, especially when handling multiple subjects, faculty availability, and classroom constraints. It often results in clashes and inefficient scheduling.

---

## 💡 Solution
The Timetable Generator provides an intelligent automated system where:
- Admins can input subjects, faculty, and constraints
- The system generates optimized, conflict-free timetables
- Faculty and students can easily view and download schedules
- An AI chatbot assists users with timetable queries

---

## ✨ Key Features
- 🧮 Automatic timetable generation
- 👨‍🏫 Faculty & subject allocation
- 🏫 Classroom and slot management
- 🤖 AI chatbot for timetable queries
- 📄 Timetable export in PDF format
- 🔍 Clash detection & validation
- 🌐 Web-based responsive interface
- 🎨 Clean and user-friendly UI

---

## 🛠️ Tech Stack (Google & Open Source)
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python (Flask)  
- **AI Chatbot:** Google Gemini API  
- **Hosting:** Render  

---

## 🏗️ System Architecture
Web UI → Flask Backend → Timetable Algorithm → AI Chatbot → Firebase Database → PDF Generator
